# agg-model-NAtlantic
This is the GitHub repo for my model of aggregation in the North Atlantic, using particle size data from Argo floats and other observations taken on the DY180 cruise (BIOCARBON).
This formed the basis of my MSc research project in marine biogeochemistry and modelling, and will continue to be developed in future. 

Files include:

Agg_model.ipynb - this is the actual model. You will need to run the first cell to initiate depth vectors etc, and then the model should work after that.

Float_obs.ipynb - this is a script for reading in and plotting each individual float profile, according to the cumulative cross-sectional area concentration.

UVP_Float_Data.xlsx - this is an Excel sheet of the data from the floats, which the script reads in using its formatting. 

Temp_binned.xlsx - this is an Excel sheet of temeprature data per depth per float profile.

Sal_binned.xlsx - this is an Excel sheet of salinity data per depth per float profile.
